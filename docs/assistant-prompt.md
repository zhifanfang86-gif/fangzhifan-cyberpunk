# 站内助手提示词设计

版本：3.6.4。运行位置：worker-script.js 的 CHAT.SYSTEM_PROMPT。

参考项目：https://github.com/richards199999/Thinking-Claude

参考文件：model_instructions/v5.1-extensive-20241201.md（社区项目，MIT）。本项目用原创中文表达借鉴自检、考虑不同解释、按问题复杂度调整回答深度的通用方法，没有复制其长篇提示词、示例或 Claude 身份设定。

只输出结论、必要依据和下一步，不要求展示内心独白。明确区分站内助手与站主，限定已知站点信息，不虚构报价、案例、实时搜索或执行能力。仅在访客确实讨论合作时引导咨询，普通问题正常交流。模型和调用预算不变。

验收：导航 DOM 和提示词约束测试属于结构性回归，不代表对模型行为的绝对保证。发布后用实际回复抽测身份、时效性信息、合作承诺和普通技术问答；提示词不能代替后端安全控制。
